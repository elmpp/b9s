B9s: Beads issues for developers and product owners
===================================================

1. Drag B9s to Applications.
2. Open B9s from Applications. On a build without a Developer ID signature,
   macOS asks once: right-click B9s, choose Open, then Open again.
3. B9s creates a sample project in the B9s folder of your home folder, offers
   to install the b9s and bd commands, and opens the project in your browser
   or in Terminal.

The browser view suits planning and review. The terminal view suits
developers. Both read and change the same Beads issues, so a product owner and
a developer always look at one list of work.

Your own projects: put a Beads project (a folder with .beads in it) in the B9s
folder and pick it from the project list in the browser. In Terminal, run b9s
in any folder that holds a .beads folder.

Included: b9s (https://github.com/vanderheijden86/b9s) and bd, the Beads CLI
(https://github.com/gastownhall/beads). Both are MIT licensed; the licenses
are in B9s.app/Contents/Resources/licenses.
